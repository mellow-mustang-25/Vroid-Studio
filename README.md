## 📖 About

VRoid Studio is a desktop character modeling tool developed by Pixiv, aimed at artists, streamers and game creators who want to build stylized 3D avatars without a deep background in 3D modeling software. It supports hair, face, body and outfit customization, live parameter editing, texture painting, and export to common 3D formats such as VRM and glTF. Recent builds have improved the hair editing brush, expanded preset libraries and refined the export pipeline for VTuber and VRChat style workflows.

## 🛠️ Troubleshooting

| Problem | Solution |
|---|---|
| Setup file blocked by SmartScreen | Click **More info**, then **Run anyway**. |
| Installer window closes immediately | Reboot, then run the setup file again from a local folder. |
| 3D preview is blank or black | Update your graphics driver and confirm DirectX 11 is available. |
| App is slow when editing hair | Lower preview resolution and close other GPU heavy apps. |
| Export to VRM fails | Check available disk space and shorten the project name. |
| Fonts or UI look scaled wrong | Adjust Windows display scaling to 100 percent and restart. |
| Project file will not open | Confirm the file was saved by the same version of the app. |
